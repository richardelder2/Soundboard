# Causal Calculus: The Fundamental Grammar of Plot

The human brain is an evolutionary causal-inference engine. It rejects sequences of events that lack rigorous causal necessity. 

A plot is not a sequence of events. A plot is a chain of **actionable causes and irreversible consequences**.

---

## 1. The Three Logical Connectors

*   **"And Then..." (The Episodic Death of Narrative):**
    *   *Structure:* Event A happens. And then Event B happens. And then Event C happens.
    *   *Cognitive Failure:* The reader's brain disengages because Event B did not require Event A. It feels like arbitrary authorial dictation.
*   **"Therefore..." (Causal Consequence):**
    *   *Structure:* The protagonist does X, **therefore** consequence Y erupts.
    *   *Cognitive Engagement:* Simulates real-world agency and accountability.
*   **"But..." (The Friction Obstacle / Complication):**
    *   *Structure:* The protagonist attempts Y, **but** obstacle Z intervenes.
    *   *Cognitive Engagement:* Generates tension and forces an escalating recalculation of tactics.

---

## 2. Invariant Rule for SAGA Planning & Drafting

**The "Therefore / But" Replacement Rule:**
Examine every transition between paragraphs, scenes, and chapters. If you can replace the transition with *"And then..."*, the scene has failed causal grammar. It must be rewritten so the link is strictly:
> **[Action A occurred] -> THEREFORE -> [Consequence B resulted] -> BUT -> [Obstacle C erupted].**
